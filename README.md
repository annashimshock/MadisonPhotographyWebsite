# Madison Photography Website

A responsive photography portfolio website developed for a real client to showcase their photography, introduce their work, and provide visitors with an accessible, visually appealing browsing experience.

**[View Live Website](https://annashimshock.github.io/MadisonPhotographyWebsite/)**

## Overview

This project involved designing and developing a photography portfolio website using HTML, CSS, and JavaScript. The goal was to create a clean, minimal design that highlights the photography while providing a smooth browsing experience across desktop and mobile devices. To ensure the site loads quickly without sacrificing image quality, the project also includes a custom Python automation script to handle image compression before deployment.

## Features

- **Responsive Design:** Adapts the layout to different screen sizes and devices.
- **Image Gallery:** Presents photography in an organized, visually focused layout.
- **Automated Image Optimization:** Uses a custom Python script to batch-resize and compress high-resolution client photos, ensuring fast page load speeds.
- **Minimalist Interface:** Uses a clean design to keep the focus on the photography.
- **Client-Focused Development:** Built to meet the needs of a real client.
- **Live Deployment:** Published using GitHub Pages.

## Technologies Used
